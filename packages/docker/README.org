* Docker

The image is built from =packages/docker/Dockerfile= (multi-stage: the
programs are compiled in a =golang:1.25-alpine= stage and copied into a
plain =alpine= runtime image):

#+BEGIN_SRC sh
  make docker            # builds mikeyaustin/greyd:go
  docker run --rm -p 8025:8025 mikeyaustin/greyd:go
#+END_SRC

The container runs =greyd -F= with =greyd.docker.conf= (dummy firewall,
sqlite database under =/tmp=, logging to stdout). Add
=--cap-add=NET_ADMIN= and switch the firewall driver to =netfilter= to
manage the host's ipsets.

=packages/docker/docker-compose.test.yml= starts throw-away MySQL and
PostgreSQL servers for =make test-db-docker=.
