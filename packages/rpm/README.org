* Building RPMs

The Go port has no C library build dependencies. Building the RPM needs
only =golang= (>= 1.25), =make= and the usual =rpm-build= tooling:

#+BEGIN_SRC sh
  make dist
  cp dist/greyd-*.tar.gz ~/rpmbuild/SOURCES/
  sed -e 's,@PACKAGE@,greyd,g' -e 's,@PACKAGE_VERSION@,1.0.0,g' \
      packages/rpm/greyd.spec.in > ~/rpmbuild/SPECS/greyd.spec
  rpmbuild -ba ~/rpmbuild/SPECS/greyd.spec
#+END_SRC

The =greyd.repo= file and the signing public key =greyd_pkg_sign_pub.asc=
in the parent directory are unchanged from the C releases.
